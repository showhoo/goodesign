# Goodesign — Diseño de interiores y home staging virtual con IA, a partir de una sola foto

[English](README.md) · [简体中文](README.zh-CN.md) · [日本語](README.ja.md) · [한국어](README.ko.md) · [Deutsch](README.de.md) · [Italiano](README.it.md) · [Español](README.es.md)

**Goodesign** ([www.goodesign.io](https://www.goodesign.io)) es un sitio de diseño de interiores y home staging virtual basado en inteligencia artificial. Sube una foto de una habitación, elija un estilo o describa lo que quiere, y recibe el render de esa misma habitación con el cambio aplicado. Está pensado para quienes tienen que conseguir que una habitación resulte convincente antes de que exista: agentes que publican una propiedad vacía, propietarios que planifican una reforma, profesionales del home staging que proponen una dirección y vendedores que necesitan fotos que detengan el desplazamiento del feed.

Aquí no hay código fuente. Esta página sirve para señalar el producto, explicar qué hace de verdad y dejar constancia de las partes sobre las que la gente sigue preguntando: la biblioteca de estilos, las páginas de tareas, los precios y la cobertura de idiomas.

## Qué hace

**Cambiar el estilo de una habitación.** Una habitación vacía o pasada de moda, mostrada en otra dirección. La biblioteca reúne 31 estilos con nombre — Japandi, Scandinavian, Wabi Sabi, Mid Century, Boho, Industrial, Art Deco, Quiet Luxury, Mediterranean, Korean, Japanese Modern, Modern Chinese, Cream, Natural Wood, Maximalist y dieciséis más — o un brief escrito por usted.

Funciona con créditos. Un crédito equivale a una imagen; la cuenta gratuita empieza con 5 créditos y no exige tarjeta. Los planes de pago son mensuales y puede cancelar cuando quiera.

## Idiomas

El sitio sirve siete idiomas. Todos contienen las mismas 240 páginas — la biblioteca de estilos, las páginas de tareas, el centro de conocimiento, las páginas legales y las páginas de comparación y ranking — con alternativas `hreflang` y un `x-default`. Cada idioma se abre mediante un prefijo de ruta, de modo que el lector llega a su propia versión del contenido.

## Para quienes construyen, y para los bots

- **`llms.txt`** está publicado en [www.goodesign.io/llms.txt](https://www.goodesign.io/llms.txt), y la política para rastreadores de [robots.txt](https://www.goodesign.io/robots.txt) permite los user agent de los principales servicios de IA y de los motores de respuesta, en lugar de bloquearlos.
- **Datos estructurados.** La página de precios incluye un bloque `Product`/`Offer` con los cinco niveles y sus precios, para que un modelo o un buscador lea las cifras en lugar de deducirlas del markup.
- **Stack.** Next.js App Router con React Server Components y Tailwind CSS, una build independiente detrás de un proxy inverso y una CDN. El contenido de cada locale se sirve desde directorios de rutas estáticas, no desde una reescritura basada en cookies.
- **No está en este repositorio.** Código fuente de la aplicación, direcciones de infraestructura, claves, detalle interno de costes o de niveles de modelo, y cualquier información sobre cuentas de clientes. Pregunte antes de reutilizar cualquier parte del texto de esta página.
