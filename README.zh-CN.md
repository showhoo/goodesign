# Goodesign — 从一张照片出发的 AI 室内设计与虚拟软装

[English](README.md) · [简体中文](README.zh-CN.md) · [日本語](README.ja.md) · [한국어](README.ko.md) · [Deutsch](README.de.md) · [Italiano](README.it.md) · [Español](README.es.md)

**Goodesign**（[www.goodesign.io](https://www.goodesign.io)）是一个 AI 室内设计与虚拟软装网站。您上传一张房间照片，选择一种风格，或者写下自己的要求，得到的是同一间房间的渲染图，只是已经带上了您所要求的改动。它面向的是那些必须在房间真正成形之前先把照片做可信的人：挂牌空房的经纪人、筹划翻新的业主、需要拿方案说服客户的软装师，以及需要照片能让人停下浏览的卖家。

这里没有源代码。这个页面存在的意义，是指出产品入口、说明它实际能做什么，并记录人们反复追问的那几项内容：风格库、任务页面、定价、语言覆盖。

## 它能做什么

**给房间换风格。** 把一间空房或已经过时的房间，呈现为另一种方向。风格库收录 31 种命名风格：Japandi、Scandinavian、Wabi Sabi、Mid Century、Boho、Industrial、Art Deco、Quiet Luxury、Mediterranean、Korean、Japanese Modern、Modern Chinese、Cream、Natural Wood、Maximalist，另有十六种；您也可以直接用自己的文字描述需求。

**只改一处，其余保持不变。** 任务页面才是它真正的差异所在。它没有提供一个开放式的"想象这间房间"输入框，而是每项任务都有自己的页面、自己的控件：

## 定价

按积分计费。一个积分生成一张图；免费账户初始有 5 个积分，无需绑定银行卡。付费套餐按月订阅，可随时取消。

| 套餐 | 每月 |
|---|---|
| Free | $0 · 初始 5 个积分 |
| Essential | $14 |
| Pro | $29 |
| Advanced | $49 |
| Agency | $99 |

付款通过 Creem 处理，Creem 担任记账主体；也可直接使用 PayPal。最新价格始终以 [/pricing](https://www.goodesign.io/pricing) 为准。

## 语言

站点提供七种语言版本。每一种都包含完全相同的 240 个页面：风格库、任务页面、知识库、法律页面，以及对比页与榜单页，并配有 `hreflang` 备用链接与 `x-default`。各语言版本通过路径前缀访问，读者进入的是同一篇内容自己的语言版本。

| 语言版本 | 入口 |
|---|---|
| 英文（默认，无路径前缀） | [www.goodesign.io](https://www.goodesign.io) |
| 日本語 | [/ja](https://www.goodesign.io/ja) |
| 한국어 | [/ko](https://www.goodesign.io/ko) |
| Deutsch | [/de](https://www.goodesign.io/de) |
| Français | [/fr](https://www.goodesign.io/fr) |
| Español | [/es](https://www.goodesign.io/es) |
| العربية（从右向左书写） | [/ar](https://www.goodesign.io/ar) |

所有语言版本的 slug 都保持英文，因此 `/ja/virtual-staging` 和 `/de/virtual-staging` 是同一个页面的两种语言。

## 面向开发者，也面向机器

- **`llms.txt`** 发布于 [www.goodesign.io/llms.txt](https://www.goodesign.io/llms.txt)；[robots.txt](https://www.goodesign.io/robots.txt) 中的抓取策略放行主流 AI 与问答引擎的 user agent，而不是拦截它们。
- **结构化数据。** 定价页面内置 `Product`/`Offer` 数据块，写明五个套餐及对应价格，模型或搜索引擎可以直接读到这些数字，而不必从标记里去猜。
- **技术栈。** Next.js App Router，配合 React Server Components 与 Tailwind CSS；采用 standalone 构建，部署在反向代理与 CDN 之后。各语言版本的内容由静态路由目录提供，不依赖 cookie 改写。
